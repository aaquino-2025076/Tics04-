# Laboratorio 4 - Mini App con consumo de API y control de calidad

## ¿De qué trata el proyecto?
Esta es una pequeña aplicación web donde pongo en práctica el consumo de APIs públicas, la manipulación del DOM y el control de calidad de código en el flujo de Git.

La app consume la API de **JSONPlaceholder** para mostrar una lista de usuarios y permite filtrarlos en tiempo real según lo que vayas escribiendo en la barra de búsqueda.

Además, el proyecto está configurado con **ESLint** para mantener un código limpio y **Husky** para evitar subir cambios con errores sintácticos o de estilo a Git.

---

## Tecnologías y herramientas
- HTML5, CSS3 y JavaScript vanilla.
- [JSONPlaceholder](https://jsonplaceholder.typicode.com/) (API pública).
- **pnpm** como gestor de paquetes.
- **ESLint** para el análisis estático del código.
- **Husky** para los hooks de pre-commit.
